# content — what the site publishes

Descriptive grouping. Mirrors `src/content/`, the Astro content root.

The site has exactly one content collection, so this folder holds exactly one child:
[`docs/`](./docs/README.md), mirroring `src/content/docs/`. The level is kept rather than collapsed
so the spec tree and the source tree read the same, segment for segment.

A second collection added to `src/content/` would become a sibling of `docs/` here.
